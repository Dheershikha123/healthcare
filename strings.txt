- Model feature importance does not establish causality.
- This is an analytics demonstration, not a clinical decision system.

### Classification
**Logistic Regression**
- Accuracy: 0.9272
- Precision: 0.4037
- Recall: 0.9575
- F1: 0.5680
- ROC-AUC: 0.9847
**Random Forest**
- Accuracy: 0.9305
- Precision: 0.4141
- Recall: 0.9375
- F1: 0.5744
- ROC-AUC: 0.9825
The classification models achieve high recall on the minority high-cost class, while precision is lower, reflecting the trade-off created by the imbalanced 5% target group.
### Regression
**Linear Regression**
- MAE = 2.5894 days
- RMSE = 3.8043 days
- R² = 0.5539
**Random Forest**
- MAE = 2.5477 days
- RMSE = 3.7715 days
- R² = 0.5615
Both models provide measurable predictive performance for LOS, with the Random Forest showing slightly lower MAE and RMSE and a slightly higher R² on the current test split.
⚠️ Limitations
1. The dataset is a historical hospital dataset and reflects only the variables available in it.
2. Missing insurance values were retained as `Unknown`; they were not artificially inferred.
3. Extreme healthcare costs and LOS values were retained because they may represent legitimate clinical cases.
4. Correlation does not establish causation.
5. Classification uses a dataset-derived 95th-percentile threshold.
6. Classification performance is affected by the approximately 5% high-cost class imbalance.
7. Regression predictions cannot capture factors absent from the dataset.
8. The ML models are analytical demonstrations and are not clinical decision-making systems.
🎯 Project Summary
The Patient Health Record Analytics & Monitoring Dashboard integrates data preprocessing, exploratory analysis, multi-dimensional drill-down analytics, financial and hospital analysis, and predictive modeling. The system enables users to move from high-level healthcare indicators to detailed clinical, demographic, financial, hospital, admission, and outcome analysis, followed by classification and regression modeling.
